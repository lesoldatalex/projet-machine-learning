# Quickstart

1. Créer un environnement virtuel (recommandé) :
   - python -m venv .venv
   - source .venv/bin/activate  (ou `.venv\Scripts\activate` sur Windows)
2. Installer les dépendances :
   - pip install -r requirements.txt

3. Lancer les notebooks (ex: `notebooks/pipelinemodel.ipynb`).

Notes :
- Si `torch` n'est pas installé, certains notebooks et scripts ne fonctionneront pas — voir instructions d'installation (CUDA vs CPU) selon ta machine.
- Les fichiers originaux ont été archivés dans `archive/` pour conserver l'historique.
